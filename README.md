# pincab-os-releases
Ce dépôt héberge les exécutables publiés de Pincab OS, utilisés par le système de mise à jour intégré à l'application (onglet Système &amp; Écrans du Setup).  Il ne contient pas le code source complet du projet — uniquement les binaires compilés (.exe) attachés à chaque release, ainsi que leurs notes de version.
